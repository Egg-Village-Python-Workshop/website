稟告主公：為何需要奇術？​

主公可曾遇過此種困境：每次要臥龍神算助你辦一件事，都得貼上一大段說明？

「請用我軍的插旗格式，格式如下：feat(scope): 描述，且...（以下三百字軍令）」

每次開新一場戰役便要重複貼上一遍。更慘的是，若你有三十份這樣的「工作說明書」，全部塞進軍令總諭，不但糧草爆炸，臥龍神算的注意力也會被稀釋——什麼都想做，反而什麼都做不精。

奇術就是解決此問題的機制。

其核心思想甚為簡單：按需調兵，用多少拿多少。
