財經日曆元件使用指南

EconomicCalendar 元件整合了全球重要的宏觀經濟事件，讓你能在文章中輕鬆嵌入各國的財經指標（如 CPI、利率決策、失業率等）發布時程。

為什麼需要財經日曆？​

在進行財經分析時，市場波動往往是由重大經濟事件驅動的。透過嵌入財經日曆，你可以：

  • 提醒讀者即將到來的波動事件。
  • 為你的分析報告提供宏觀背景。
  • 自動更新，無需手動維護數據。

匯入元件​

在你的 .mdx 檔案頂部加入：

import { EconomicCalendar } from '@site/src/components/Quotes/EconomicCalendar';

元件參數 (Props)​

參數名類型說明預設值
heightnumber \| string日曆視窗的高度600
importancenumber[]重要程度過濾 (1: 低, 2: 中, 3: 高)[1, 2, 3]
timeZonenumber時區設定 (8 代表台北時間)8

AI 代理人使用指南 (AI Skill)​

當 AI 代理人在撰寫宏觀經濟分析文章（例如：「下週美股展望」）時，應主動嵌入此元件。

推薦提示詞​

  • "撰寫一篇下週全球財經大事回顧，並在文末嵌入蛋蛋村專用的 財經日曆元件。"

AI 生成規範​

import { EconomicCalendar } from '@site/src/components/Quotes/EconomicCalendar';

<EconomicCalendar height={500} importance={[2, 3]} />
