進階報價元件與 AI Skill 實戰

本文件將教導你如何使用蛋蛋村專屬的進階戰情室元件，包含 列表模式 (StockRow)、五檔報價 (TabOrderBook)，以及如何透過 資料中心 (useQuotes) 取得即時數據。

這些元件已經深度整合了 Docusaurus 的架構，並支援 MDX 直接渲染。

匯入元件與 Hook​

要在 MDX 或是自訂的 React 頁面中使用這些進階元件，你必須先引入它們：

// 引入 UI 元件
import { StockRow } from '@site/src/components/Quotes/StockRow';
import { TabOrderBook } from '@site/src/components/Quotes/ModalTabs/TabOrderBook';

// 引入資料層 Hook (若在 React 元件中開發需要即時更新時使用)
import { useQuotes } from '@site/src/components/Quotes/store/QuoteContext';

元件說明​

1. StockRow (精簡列表元件)​

適合用於側邊欄、懸浮視窗或空間有限的清單式呈現。

Props 參數：

  • data (StockData, 必填): 包含 symbol, price, change, changePercent, name 的物件。
  • alertConfig (Object, 選填): 包含 min 與 max 的警示設定。

2. TabOrderBook (五檔報價元件)​

專業的左右對稱五檔掛單深度圖，會根據掛單量自動繪製背景能量條。

Props 參數：

  • realTimeData (StockData, 必填): 除了基本股價資訊外，必須包含 asks 與 bids 陣列。每個陣列元素需具備 price 與 volume。

AI 代理人使用指南 (AI Skill for Claude Code & Gemini)​

如果你是 AI 代理人，在協助使用者建立自訂儀表板或技術分析文章時，請遵循以下 Skill 指引：

1. 偵測開發需求​

  • 當使用者要求「我要一個緊湊的股票清單」、「幫我加上五檔報價」，請使用 StockRow 與 TabOrderBook。
  • 當使用者要求「請幫我抓最新的報價資料」，請在 React 元件中使用 const { quotes, loading } = useQuotes(['0050', '2330']);。

2. 生成 MDX 靜態範例的規範​

在 MDX 檔案中，AI 無法直接執行 React Hook (useQuotes)。因此，若要在 MDX 中展示元件，必須使用靜態的 Mock Data 直接傳給元件。

3. Skill 代碼範例 (MDX 內部展示)​

當 AI 要為 0050 生成五檔報價區塊時，請輸出：

import { TabOrderBook } from '@site/src/components/Quotes/ModalTabs/TabOrderBook';

<div style={{ maxWidth: '400px', margin: '0 auto' }}>
  <TabOrderBook realTimeData={{
    symbol: "0050",
    name: "元大台灣50",
    price: "150.25",
    change: "+1.25",
    changePercent: "+0.84%",
    asks: [
      { price: 150.7, volume: 150 },
      { price: 150.6, volume: 320 },
      { price: 150.5, volume: 800 },
      { price: 150.4, volume: 1250 },
      { price: 150.3, volume: 500 }
    ],
    bids: [
      { price: 150.2, volume: 600 },
      { price: 150.1, volume: 1500 },
      { price: 150.0, volume: 3000 },
      { price: 149.9, volume: 850 },
      { price: 149.8, volume: 400 }
    ]
  }} />
</div>
